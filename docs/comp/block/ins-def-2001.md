# 选择结算单

::: tip 组件说明
此组件用于选择和管理采购结算单信息，支持按负责人搜索、模糊搜索、包含已申请筛选、结算单选择/取消选择、作废退回等功能。常用于采购报销流程中关联招采系统结算单。
:::

## 功能特性

- 支持按负责人搜索结算单
- 支持结算单号/合同名称模糊搜索
- 支持"包含已申请"筛选
- 支持结算单选择/取消选择（已选行置顶并高亮）
- 支持已申请结算单提示（悬浮显示申请人、业务单号、经办人电话）
- 支持结算单作废退回（带确认提示）
- 支持表格分页
- 显示结算单号、合同名称、结算类型、经费项目、本次结算金额

## API

本组件无 props。

### 方法

| 方法名 | 说明                   | 类型         |
| :----- | :--------------------- | :----------- |
| load   | 重新初始化并加载列表   | `() => void` |
| save   | 保存（预留，无实际逻辑） | `() => void` |

### 事件

| 事件名  | 说明               | 类型         |
| :------ | :----------------- | :----------- |
| re-load | 需要刷新框架时触发 | `() => void` |

## 接口说明

以下接口均请求 `POST /ExpenseApplyUInsV2`。

### 初始化

组件创建及重新加载时调用，获取默认负责人与已选结算单列表。

**请求参数**

| 字段 | 类型      | 是否必传 | 示例         | 说明         |
| ---- | --------- | -------- | ------------ | ------------ |
| ajax | `Boolean` | 是       | true         | 默认         |
| act  | `String`  | 是       | confirm_init | 接口方法     |

**响应示例**

```json
{
    "success": true,
    "objectMap": {
        "charge_uid": "",
        "insappList": []
    }
}
```

### 搜索加载

按筛选条件重新加载结算单列表（服务端筛选）。

**请求参数**

| 字段       | 类型      | 是否必传 | 示例       | 说明                             |
| ---------- | --------- | -------- | ---------- | -------------------------------- |
| ajax       | `Boolean` | 是       | true       | 默认                             |
| act        | `String`  | 是       | confirm_load | 接口方法                       |
| contract   | `String`  | 否       |            | 结算单号/合同名称（模糊搜索）    |
| charge_uid | `String`  | 否       |            | 负责人                           |
| isApply    | `String`  | 是       | F          | 是否包含已申请：T-是、F-否       |

**响应示例**

```json
{
    "success": true
}
```

### 结算单列表分页

**请求参数**

| 字段  | 类型      | 是否必传 | 示例           | 说明     |
| ----- | --------- | -------- | -------------- | -------- |
| ajax  | `Boolean` | 是       | true           | 默认     |
| act   | `String`  | 是       | confirm_pagging | 接口方法 |
| page  | `Number`  | 是       | 1              | 当前页   |

**响应示例**

```json
{
    "success": true,
    "list": [],
    "pagging": [10, 1, 0]
}
```

### 选择/取消选择结算单

选中或取消选中后，将当前全部已选 `request_id`（逗号分隔）提交保存。

**请求参数**

| 字段       | 类型      | 是否必传 | 示例               | 说明                     |
| ---------- | --------- | -------- | ------------------ | ------------------------ |
| ajax       | `Boolean` | 是       | true               | 默认                     |
| act        | `String`  | 是       | confirm_save       | 接口方法                 |
| request_id | `String`  | 是       | JSD001,JSD002      | 结算单号（逗号分隔全量） |

**响应示例**

```json
{
    "success": true
}
```

### 作废退回结算单

**请求参数**

| 字段       | 类型      | 是否必传 | 示例         | 说明         |
| ---------- | --------- | -------- | ------------ | ------------ |
| ajax       | `Boolean` | 是       | true         | 默认         |
| act        | `String`  | 是       | confirm_cancel | 接口方法   |
| request_id | `String`  | 是       | JSD001       | 结算单号     |

**响应示例**

```json
{
    "success": true
}
```
